The trick: the last bit doesn’t matter (much)

Sound is stored as a long list of numbers called samples. Each one is 16 bits, so it goes from −32,768 to 32,767. Video frames are made of pixels, and each pixel is three 8-bit numbers for red, green and blue.

If you change only the last bit of one of those numbers, its value moves by 1. Nobody can hear that or see it. So those last bits are free space, and that’s where we put the secret.

What happens when you click “Hide it”

  1. Your message or picture gets compressed (zlib) so it takes less space.
  2. If you gave a password, we turn it into a key (PBKDF2, 200,000 rounds) and encrypt with AES-256-GCM. A wrong password is caught instead of giving you garbage.
  3. We put the length in front, so the extractor knows when to stop.
  4. The password also decides where the bits go: a random shuffle of all the samples or pixels. The changes end up spread over the whole file instead of bunched at the start.
  5. We overwrite the last bit (or last few bits) of each chosen sample.
  6. We save the result in a lossless format: WAV for audio, MKV with the FFV1 codec for video. The video’s original sound is copied over unchanged.

Why WAV and MKV, not MP3 and MP4? MP3 and MP4 make files small by throwing away detail you can’t hear or see, and that’s exactly where the secret is. If you convert the file or send it through WhatsApp or YouTube, the message is lost. The MP4 preview on the Hide page is only there so your browser can play it.
